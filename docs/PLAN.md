# hwy-label — 라벨 스티커 메이커 계획서 (v0.1 draft)

라벨 프린터(Epson LabelWorks)로 뽑은 듯한 라벨 스티커를 만들고, 서랍에 모아 PNG/ZIP/한 판 이미지로 내려받는 정적 웹사이트.
배포: GitHub Pages (`xngsuii/hwy-label`), 서버 없음. 모든 데이터는 브라우저(IndexedDB)에 저장.

---

- 왼쪽 사이드바: PREVIEW + [새로]/[서랍에 넣기]는 상단 고정, 그 아래 편집기만 스크롤

- 디자인 톤: 쿨톤 뮤트 핑크 `#DDB9C8` / 화이트 `#FFFDFD` / 딥그레이 `#2F2C30`
- 크로스스티치 패턴 배경, 하프톤 점, 비트맵(픽셀) 아이콘·폰트, 얇은 테두리 + 소문자 대문자 라벨 헤더 (engine.lol 느낌)
- 모바일: 3단 → 탭 전환(만들기 / 판 / 서랍) 1단 레이아웃

## 2. 기능 범위

### 2-1. 라벨 에디터 (왼쪽)
| 항목 | 내용 |
|---|---|
| 방향 | 가로형 / 세로형(세로쓰기) / 정방형 / 자유형(가로·세로 mm 입력·고정) |
| 테이프 폭 프리셋 | 4 · 6 · 9 · 12 · 18 · 24 · 36 · 50 mm (Epson LW 규격) + 직접 입력 |
| 자동 늘어남 | 가로형: 글자 수만큼 길이 증가. 줄바꿈 시 **기본은 테이프 폭 고정 + 글자 축소**(실제 프린터 방식), 옵션으로 "높이 늘림" |
| 내부 여백 | 상하 / 좌우 mm 슬라이더 |
| 텍스트 | 정렬(왼/가운데/오른/양쪽), 볼드·이탤릭·밑줄·취소선·외곽선 |
| 타이포 | 폰트, 크기, 자간, 행간, 장평 — 라벨별 개별 값 + 기본값 + 타이포 프리셋 저장 |
| 프레임(기본) | 없음 · 실선 · 점선 · 이중선 (프레임 선택 시 텍스트는 프레임 안 영역으로) |
| 프레임(특수) | 뮤직 플레이어 · 메신저 · 도그태그 · 원고지 · 말풍선(일반) · 말풍선(캐릭터가 말하는) · 오마모리 |
| 배경 무늬 | 없음 · 체크(깅엄) · 줄무늬 · 도트 · 사선 (밀도·잉크색 투명도 조절) |
| 장식(데코) | 상/하/좌/우 슬롯에 각각 하나씩. 기본은 좌우 양쪽. 픽셀 아이콘 라이브러리 + 업로드 이미지 |
| 이미지 → 비트맵 | 업로드 → 하프톤(점) / 디더링(Floyd–Steinberg, Bayer) / 임계값 → 잉크색 1색으로 데코 슬롯에 바로 삽입 |
| 이모지 | 기본: 흑백 유니코드 글리프로 변환(라벨프린터처럼 잉크색 1색). 토글로 컬러 이모지 유지 (확정) |
| 자주 쓰는 이모티콘 | 카오모지·기호 팔레트 (ʕ•ᴥ•ʔ, ♡, ☆, ✿ …) + 즐겨찾기 추가 |
| 색 | 현재 판 팔레트에서 테이프색 / 잉크색 선택 |

### 2-2. 판 & 서랍 (가운데 + 오른쪽)
- **서랍**: 완성 라벨 목록(썸네일). 선택 체크, 다시 편집, 복제, 삭제, 순서 변경
- **판 배경**: 커팅매트 그리드 / 단색 / 모눈 / 투명 / 업로드 이미지
- **판 크기**: 1080×1080, 1080×1350, 1080×1920, A4, 직접 입력
- **배치**: 자동배치(줄맞춤 패킹) / 흩뿌리기(랜덤 회전, 2번 이미지 느낌) → 이후 드래그 이동·회전·크기·앞뒤 순서 자유 변형
- **컬러 프리셋**: 판 하나에 최대 6색 팔레트. 기본 상태는 "커스텀"(자유 편집), 마음에 들면 프리셋으로 등록 → 불러오기. 라벨은 이 팔레트에서 테이프색/잉크색 선택
- **로컬 자동 저장**: 편집 중인 라벨, 서랍, 판 배치, 팔레트·타이포 프리셋, UI 설정을 IndexedDB에 자동 저장 → 새로고침/재방문 시 복원. 백업용 JSON 내보내기/불러오기도 제공
- **PRINT!** 
  - 라벨 PNG 개별 다운로드(선택한 것만) / ZIP 일괄
  - 한 판 PNG
  - 해상도: 180 dpi(실제 LW 출력 해상도) / 300 / 360 dpi, 투명 배경 옵션

### 2-3. 폰트
- 무료·웹 임베드 가능한 폰트는 CDN(jsDelivr/눈누) 로드
- **웹폰트 임베드**: URL(CSS / woff2) 붙여넣기 or 내 컴퓨터 폰트 파일 업로드(브라우저에만 저장, 서버 업로드 없음)

| 폰트 | 판단 | 비고 |

| G마켓 산스 | ✅ 가능 | 상업 이용·웹 임베딩 무료 |

## 4. 기술 스택

- **빌드 없는 정적 ES 모듈** + **Preact/htm (CDN)** — 로컬에 Node가 없어도 수정·배포 가능, 저장소 루트가 곧 사이트
- 라벨 렌더링: **Canvas 2D** 단일 렌더러 → 미리보기·썸네일·PNG 출력이 픽셀 단위로 동일
  - mm → px: `px = mm / 25.4 × dpi`
  - 세로쓰기, 장평(`scale x`), 외곽선(`strokeText`), 패턴/하프톤 직접 그림
- 판 편집: Canvas + 자체 드래그/회전 핸들
- 저장: IndexedDB(서랍·프리셋·업로드 폰트/이미지), localStorage(UI 상태)
- 다운로드: JSZip + `canvas.toBlob`
- 배포: GitHub Pages (Deploy from branch, main / root)

## 6. 진행 단계

1. ~~M0 와이어프레임 검토~~ ✅
2. ~~M1 뼈대~~ ✅ 정적 사이트, 3단 레이아웃, 디자인 토큰
3. ~~M2 라벨 렌더러~~ ✅ (1차) 텍스트·폰트·크기 프리셋·여백·정렬·스타일·기본 프레임·배경 무늬
4. ~~M3 서랍 + PRINT!~~ ✅ (1차) 서랍, 로컬 자동 저장, 백업/복원, PNG/ZIP, 컬러·타이포 프리셋, 내 폰트 추가
5. **M4 판**: ✅ 자동배치·흩뿌리기·드래그·회전·순서, 판 배경, 판 PNG / 남은 것: 크기 핸들, 직접 회전 핸들, 커스텀 판 크기
6. **M5 장식**: ✅ 픽셀 아이콘·상하좌우 슬롯·이모지 흑백 변환·이모티콘 팔레트 / 남은 것: 이미지 하프톤/디더링, 아이콘 추가
7. **M6 특수 프레임**: 뮤직 플레이어 → 메신저 → 말풍선 2종 → 원고지 → 도그태그 → 오마모리
8. **M7 폰트 확장 + 모바일 + 다듬기**: 웹폰트 임베드, 로컬 폰트, 반응형
